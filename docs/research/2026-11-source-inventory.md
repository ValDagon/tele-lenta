## Findings

1. **Eight of the nine given sources are groups.** The web preview covers one source,
   `montework` (5,661 subscribers). The group audience is roughly 58,000 members in total,
   with overlaps. The safe, account-free ingestion path therefore covers a small fraction
   of the product.
2. **There are no Serbian sources.** Every source is Montenegro. The "Сербия" filter would
   be empty, and the "partially Serbia" part of the brief is not represented by this list.
3. **`montenegro_top_chat` is not a board.** It is a general life/work chat; its own
   description points to `prodai_montenegro` (bazaar) and `nedviga_montenegro` (real
   estate) as the listing chats. Including it as a source means high noise. The two
   sub-chats are better sources.
4. **`monteafisha` is the better events source.** It is a channel (preview works) with
   structured event posts (date, venue, city) generated by a bot. `sutomoremontenegro` is a
   539-member community group, useful for local Sutomore announcements but not a feed.
5. **`montework` is the ideal parser pilot.** Channel, preview works, structured job posts
   with salary and city, no consent needed.
6. **`montenegro_market` is goods only.** Its description explicitly redirects housing and
   jobs elsewhere, so it should not be classified as a general board.
7. **`saleme_job` carries hashtags** (`#ВАКАНСИИ`, `#РЕЗЮМЕ`), which is a useful
   classification signal but not a substitute for text classification.
8. **The list is the Russian-speaking expat market.** Local Montenegrin and Serbian
   classifieds (e.g. `oglasi.me`, `autodiler.me`) are absent. If the target audience
   includes locals, the source list needs a second track.

## Implications

- Public group messages are readable anonymously through
  `https://t.me/<group>/<id>?embed=1`. No account, bot, or admin is required; see the
  correction in `2026-11-telegram-ingestion.md`.
- The constraint is therefore request budget and HTML fragility, not access. A per-group
  cursor and an adaptive ID window are the core of the collector.
- `montework` and `monteafisha` remain the cheap channel sources: one page returns 20
  messages and needs no enumeration.
- Serbia needs its own source list before the region filter means anything.
