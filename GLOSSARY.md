# Теле-Лента

A Telegram Mini App that turns listings from many Montenegrin and Serbian source
chats into one feed, with a link back to every original message.

## Language

**Объявление**:
A publication in a source chat that offers, seeks, or announces a good, service,
job, or property.
_Avoid_: пост, лот, объява

**Источник**:
A Telegram chat or channel that the service reads listings from.
_Avoid_: канал, паблик

**Кластер**:
A set of listings judged to describe the same offer, usually cross-posted across
several sources.
_Avoid_: дубль, копия, репост

**Карточка**:
The feed's single display unit for one cluster.
_Avoid_: объявление (when the card is meant), пост

**Секция**:
A top-level feed division: Объявления, Вакансии, or Мероприятия.
_Avoid_: раздел, таб

**Категория**:
A facet inside Объявления: Недвижимость, Авто, Вещи, Услуги, Другое.
_Avoid_: рубрика, тип

**Регион**:
Черногория or Сербия, assigned from the source chat and never inferred from the
listing text.
_Avoid_: страна, локация

**Куплю/Ищу**:
A listing that expresses demand rather than supply.
_Avoid_: запрос, потребность

**Вакансия**:
A listing that offers or seeks employment.
_Avoid_: работа, джоб

**Мероприятие**:
An event with a start time and a venue, published in an events source. It is not a listing
and is not bought or sold.
_Avoid_: событие, ивент

**Сохранённый поиск**:
A user's query and filters stored for repeated matching against new listings.
_Avoid_: подписка, алерт

**Дайджест**:
A batched notification with new matches for one or more saved searches, sent on
an interval.
_Avoid_: пуш, уведомление (when the batched form is meant)
